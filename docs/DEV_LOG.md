## 2026-08-21 01:29 +08:00

### 路线局部节拍与世界幕对齐
- 确认原有五步节拍仍是叙事骨架：`setup -> escalation -> pressure -> climax -> payoff`。本轮没有将其替换为按年龄的线性状态机。
- 将节拍记录从单一 `activeScene` 拆为世界包路线维度的 `routeProgress`。引擎只读取和记录模型本回合实际选中的路线，不推导或锁死模型的路线偏好。
- 保留事件自身的 `narrativeBeat` 编码以及“模型选路线、引擎选具体素材”的职责分工；没有补充通用兜底素材，也没有改动年龄或停表逻辑。
- 一条路线完成 payoff 后只清理该路线的局部进度，世界幕前进；其它路线保持可回收的既有进度。三幕 payoff 后再沿用现有结局审批。
- 补充并行路线回归断言：获胜路线重置、并行路线进度保留。后端测试 21/21 通过，后端构建通过。

## 2026-08-22 01:34 +08:00

### 叙事属性平衡与结局质量
- 将普通年份与抉择年份的模型属性输出统一收敛到共享 `NarrativeAttributePolicy`，避免工具 schema、提示词解析和引擎审批各自维护不同限制。
- 普通年保持一次背景工具调用，改为每年产生一项轻/中度正向成长；背景正收益的既有节奏限制保留。
- 抉择后果分出明确数值空间：稳健不能越过轻度收益，适中不能只产生负面，冒险允许重度突破与重度挫折。属性数值仍由引擎结算，不让模型直接写任意整数。
- 名望改为属性基础加主线贡献与已落盘的抉择结果；结局资格仍仅由世界主线、事实与结局工具审批决定。
- 古代六条路线均新增普通结局蓝图；结局渲染输入显式携带引擎锁定的好/普通/坏品质，避免模型将坏结局写成死亡或将普通结局拔高为好结局。
- 回归覆盖：三档属性策略、三档叙事结局、原有五步路线和停表链路。后端测试 23/23 通过；共享包输出被本地进程锁定，未终止用户进程。
