# 边境线作者分支表

本表供开发创作、审读和验收，游戏模型不读取。运行时剧情与接续以事件组为准。边境与逐鹿使用事件协议 2、运行版本 22；其他路线不随试点改变。

## 故事与接续

| 位置／事件组 | 一件事及实际结果 | 接续与生活 |
|---|---|---|
| 军户成长 `border-childhood` | 家庭生活、成长与操练 | 山中遇敌；间隔承接童年成长 |
| 山中遇敌 `ridge-scouts` | 发现敌哨、报信并回家；被俘是另一结果 | 成功接新兵训练；被俘接归途，不补发报信成果 |
| 被俘归途 `captive-return` | 脱险或实际死亡，处理家人的代价与归来 | 存活接新兵训练；死亡交观察器判终局 |
| 实际入伍 `formal-enlistment` | 新兵训练、取得士兵职责、第一次履职 | 第一幕完成；不把一次报信当入伍 |
| 接队磨合 `company-training` | 士兵生活、接队、形成协作 | 狼谷或洪水救援互为适用经历，不要求两件全做 |
| 救援 `wolves-rescue`／`flood-rescue` | 完成救援并安顿实际幸存者 | 队伍破裂接重整；仍可行动接合编；有图且确有军需时可交图 |
| 重整 `company-rebuild` | 安顿伤亡、重组、实际守卫 | 接合编；损失继续存在，不重复原救援检定 |
| 合编出击 `border-campaign` | 合练、守渡、调整、攻营、归营，各单元只处理一事 | 胜负改变兵力、阵地、功过；存活接军议，覆灭交观察器判终局 |
| 军议 `general-commission` | 按制度处理实际功过：授将、留任、降职 | 授将接第三幕；留任／降职接军旅去留选择，不安排晋升补考 |
| 军旅去留 `service-direction` | 接受现职继续服役，或办理交接离军 | 留军以实际军职进入第三幕；离军接归乡与后续生活，不在选择当场锁结局 |
| 交图 `map-delivery` | 可选辅助经历：交付已有地图、获得对应器物 | 不替代主线成果；按已完成经历接回合编或战争，不能重走已完成组 |
| 全面入侵 `invasion-arrival` | 邻城失守、接防、交战、轮换 | 将军指挥防区，校尉／队正在上级部署下带所属部伍；均接战争决战 |
| 决战 `decisive-frontier-war` | 围困、决战、战后军议 | 战争落定接战后去留；仍受围迫接最后防线；实际死亡／事业败亡可终局 |
| 最后防线 `last-frontier-line` | 撤守、守住或反击的实际结果及处置 | 保全后接战后去留；覆亡交观察器判终局 |
| 战后去留 `postwar-direction` | 继续守边，或交权退居；选择当次落实职责安排 | 守边接和平驻防与部属成长；退居接交接、安顿和晚年 |
| 和平守边 `peace-service` | 战后职责、培养后来者与最终交接 | 实际退出军伍后接共享退役生活，不再次制造大战 |
| 退役生活 `retired-life` | 归家安顿、家计亲友、旧部往来、晚年变化 | 可承接第二幕离军或第三幕退居；前情功过、伤亡和关系各自保留，生活落定后判断结局 |

## 分支含义

- 决定人生道路的两处直接选择：军议留任／降职后的去留、战争落定后的去留。不掷点，不显示概率或预告结局等级。
- 救援为等价经历；交图为辅助经历；重整与最后防线为真实非成功后续。守渡、攻营结果可以汇合到军议，但军议不能补发未取得的军功。
- 第二幕完成表示带队实践及军职、事业结果已经成立，成为将军是较高成果。较低军职不阻止参战，也不自动等于坏结局。
- 正常交接、实际守边贡献及后续生活可以形成普通结局；实际事业覆亡仍可提前结束。选择离军本身不决定好坏。
- 事件之间的生活由素材年数范围选定并保存。正文同时知道整个间隔和本段覆盖范围；生活不预写下一事件战果。

实测发现后已做的两处针对性修改：

1. 协议 2 的已配置同幕接续不能被换幕或存活的好／普通结局跳过，真实死亡与事业败亡仍能提前结束。由通用接续状态提供边界，沿用现有观察和一次纠正，不按 IF 或军职判断。修复后完整新局确实执行入伍、战后选择及生活，旧误判返回保留在诊断抓包中。
2. 军议授将依据明确为本组合编后守渡／攻营的实际成功，区分早期迁民救援的功绩。双败来源复测改为留任，正常开放去留选择；不是在引擎增加“失败两次不得晋升”规则。首轮新局的正式授将来源实际攻营成功，符合该依据。

### 叙事未通过项及输入溯源

- 普通年份仍多次重复咳声回哨、送鞋添衣、问冷不冷；晚年交钥与册也重复。完整局 `model-0223.json`（83—84 岁）中，system 只要求按年龄写生活；稳定卡仍是开幕战争资料，当前材料没有资产目录，生活 context 是晚年生活。历史却完整保留 81—82 岁“交钥与册、菜地、补鞋、石头来访”，原返回几乎重写该段。重复来自历史内容与本次生成的交接，不能归因为资产召回；本轮没有清洗历史或重做压缩。
- 军旅期反复哨次、口令、数队也有明确材料来源：合编与磨合单元写有接号、换阵和队官协作，幕初卡把赵七盾列、石头报时机与渡口号令桩固定为开幕条件。它们有当时的军事作用，但普通生活仍过度重复使用。生活阶段与区间供应已落实，实际多样性尚未通过。
- 校尉回放 86 岁观察把已经失去东段的有限防卫判为 good，证据使用“本次入侵未破防区”，与 54 岁军议的失地公文冲突；最终证据又写“自然老病终老”，实际最后正文只写交出差事、院中听风，且 `lifeStatus=alive`。这两项是观察语义错误，本轮未通过关键字校验或改写已提交结果掩盖。
- 完整局父亲直到主角 80 岁才去世，人物代际年龄不可信。上下文细节补强按已确认范围留后处理，不恢复资产召回。

四项结论分别为：通用执行与分支接续已落实；生活能承接新阶段但重复未消除；真实死亡提前终局已验证；观察等级与证据一致性仍有未解决样本。开发者技能见 [IF 故事创作](../skills/if-story-authoring/SKILL.md)。
