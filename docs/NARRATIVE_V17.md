# 历史叙事规范：运行版本 17

更新：2026-11-03。本文保留为历史对照，当前实现见 [运行版本 18](NARRATIVE_V18.md)。

## 运行链路

进入新幕并异步准备主持资料 → 引擎按已提交交接确定年龄 → 召回相关条件 → 正文推演或提出抉择 → 保存实际结果 → 同步现状、压缩历史 → 观察整幕收束。

沿用每幕关键属性分别达标后的持续准入、成长流派、最多两轮过渡生活、现有概率公式、单次持久化掷点和求生边界。没有图记忆、剧情台账、新模型职责请求或正文改写请求。

## 九项职责与接口

| 项目 | 当前实现与权责 |
| --- | --- |
| 本幕主持资料 | `plan_act_world_card` 生成 `situation / actors / locations / pressures / stakes`；`actId / revision` 由引擎保存；`objective` 原样取 IF，`payoffMeaning` 原样映射为 `closureMeaning`。幕内不可重写。行动方不自动登记成资产，期限只作为故事条件，不由引擎核验。 |
| 正文 | 身世、普通生活、剧情主持、抉择结果、结局各用固定职责。仅剧情主持开放玩家抉择职责；登记与活动规则集中在工具字段。`render_origin` 不返回 `summary / seedHints`，开篇完成依据实际正文提交。 |
| 长期压缩 | 仅合并旧摘要与新增实际对话，合并重复、省略经过，不补写内容。身世是第一段实际对话；抉择背景、所选行动、结果作为完整输入。覆盖 ID、版本、截至年龄只管理替换范围。保留十年、幕末、终局机会。 |
| 连续性 | 判断持续价值与真实现状变化。详细候选来自本批登记／变更引用／实际活动、当前位置及直接结构化关联；其余仅供身份索引。普通三次完整经历、抉择完整事件立即同步，幕末／终局去重收尾；仍沿用前台等待，无后台维护队列。 |
| 召回 | `recall_scene_assets` 返回 `recallRefs: {ref,purpose}[]` 与可选 `assetNeeds`。目录只提供身份索引；选中后一次投影相关现状。本领来源与获得经过不进入正文；用途不是必须展示的要求，缺失对象不是寻物任务。 |
| 抉择与时间 | 抉择裁定一件完整事件。剧情正文和独立结果必须返回 `nextClock: hold \| advance`；遗漏拒绝，无默认跨年。`hold` 可包含当前岁内的行动、训练、交涉。换幕保留该交接。普通生活按实际区间提交；待选、结果、求生保持事件年龄。 |
| 属性与观察 | 属性工具只返回实际属性变化，无 `factResolution`。`observe_act_closure` 只返回 `ongoing / closed` 和收束证据，不返回缺口或布置局部待办。完整事件提交且求生处理后才能换幕；按幕和来源去重。 |
| 结局 | 一次请求根据既定等级、IF 标准、实际历史、最终状态和死亡事实评价人生。无 `distill_life_verdict`、独立人生锚点、未来幕卡或通用“主线已完成”写作模板。保留现有评分入口。Chat Completions 与 Responses 均走已配置传输。 |
| 世界材料与遗留入口 | 无 `stylePrompt / styleRules / immersionRules / worldCore.tone / endingGuide`。材料保留世界规律、制度、空间和行动知识，不提供作者指令。删除时令身份手法卡及未调用的旧关注／预定事件渲染函数；当前叙事模式不能回退到旧年度生成或旧选项生成。 |

## 资产差量与退出

- 正文只登记身份，不补全档案。`pendingDetails` 表示已知资料不足，不是待完成任务。
- 人物 `description` 记录稳定身份，`condition` 记录影响行动的个人处境，关系只记当前关系。
- 地点设施与关联保存稳定条目 ID。连续性只提交 `featureChanges / actorChanges`，已有条目按 ID 修改或 `remove:true`，新增使用 `id:"new"`。省略字段保留原值，不接收整组 `features / actors` 替换；解析时核对既有条目。
- 本领 `description` 表示是什么，`usage` 表示方法和条件，`source` 仅是档案中已知来源。宝物沿用本领类型。
- 动态事项只保存仍有效的事项、承诺、限制或已成立结果，不另写经历摘要。
- `retirements: {kind,ref}[]` 撤下无持续作用的登记。当前位置及保留记录仍引用的对象只留最小身份；解除引用后移除。故事离场／死亡与存储撤下不是同一概念。
- 归并修改结构化引用，公开正文和旧快照不改写。分类资产仍是当前存储，不引入图或另一套事实来源。

## 唯一历史与缓存

供应顺序为：固定 system 与工具 → 本幕稳定主持资料和稳定人设 → 独立的“故事历史” → 当前状态、相关材料和本轮任务。

故事历史由已压缩文本和未覆盖的实际对话组成。主角材料不再包含身世摘要或经历摘要；已覆盖原文不再重传，未压缩选择结果保持完整。旧存档中的摘要、人生提要不会成为补充输入。

年龄、目录 ID、确定成败和求生权限只出现在动态材料，不改写工具或 system。恢复会话重建当前 system，保留已提交历史。

## 存档与验证

新局使用运行版本 17。旧存档保留只读查看，不自动拆卡、清洗摘要、迁移资产或继续按新规则推进。前端保留时间线、资产面板和正文幕序，不展示后台任务提示或字段拼接简介。

自动验证检查最终发送内容、差量提交、恢复、时间交接和两种传输；不以年龄、剧情关键词、事件数量或必胜结局判定故事质量。实际叙事效果需以新局原始请求和正文对照检查。
