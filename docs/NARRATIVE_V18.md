# 当前叙事规范：运行版本 18

更新：2026-11-04。本文取代 v17 的当前规范地位；旧版本文档仅作历史对照。

## 故事与记忆

故事链路：IF 与固定幕间主持资料 → 正文推演 → 抉择裁定完整事件 → 观察实际收束。

展示维护链路：实际正文 → 维护持续有效的现状 → 前端档案及回合快照。资产召回暂停，维护结果不供应正文、幕初组织、抉择结果或结局。

主持、抉择结果、连续性和压缩职责保持既有内容；玩家正文统一补回第二人称。边镇线第一幕对齐实际入伍、第二幕对齐持续统军能力并成为将军、第三幕仍为抗击外敌。保留主持资料结构、篇幅、候选关联算法、时间交接、属性准入、流派、概率和求生规则。没有图记忆、后台维护队列、剧情台账、正文改写或额外模型请求种类。

## 事项的身份与收束

维护详情分别提供事项 ID、原名称、状态、当前进展／结果和关联引用。进展不替换事项名称；本批完整实际对话是变化依据。

- `stay`：这个 ID 所指的原事项仍待回答。
- `finish`：原事项已有实际结果；相关事项仍开放不阻止它结束。
- 新建只收纳首次成立、超出当前现场仍有持续作用的未决事项、承诺、限制或伏笔。已有事项变化使用原 ID；短期口头指示、已发生经历及人物交往不另建经历事项。“下一步怎么办”本身不是新事项。
- 内容只写本事项现状或结果，不吸收旁支任务或办理经过。
- 已结束事项退出默认维护范围；本批明确关联其新变化时可以再次供应。历史正文与结果保留。

字段含义只在最终工具字段说明中定义，不在连续性 system 另加一套写作任务。根数组无变化填 `[]`，单条未变字段省略。设施和关联逐条差量的最终 schema 同时保留内容含义与操作说明。

## 展示与叙事隔离

当前主流程不发送 `recall_scene_assets`。幕初仍通过唯一入口组织本幕世界卡；幕内直接向正文交接世界卡、人物基础、实际历史及引擎时间。展示维护不能通过当前位置、动态事项状态或其他身份索引间接影响幕初素材选择。

正文各职责的栏目白名单排除人物、地点、本领、事项及维护摘要；发送前不再追加完整身份目录。主角材料不读取展示档案的当前位置。已有档案仍用于前端与维护校验，不作为第二份故事历史。

正文保留最小身份登记。已知 ID 可继续使用；人物、地点、本领也可以用准确名称或 new＋名称登记。引擎只在同类型中唯一精确同名时复用身份，未识别或有歧义的名称形成候选，别名与歧义交由维护归并。活动中的准确名称同样有效；不能因展示整理归并或撤下旧名称而拒绝正文。候选活动与最小登记一起分配身份，不要求未分配的 ID。伪造结构化 ID 仍被拒绝，纠正请求不补回全库 ID 或人物目录。

当前抉择工具只生成 id、label、description，不要求模型绑定未供应的本领 ID 或目的地 ID；三档、核查属性、概率公式及前端成功率保持不变。旧数据中显式绑定仍按已有引用协议核验。

## 维护提交、失败与恢复

实际正文、结算、身份登记、来源和待收尾状态先保存，再进行前台维护。普通三次完整经历、完整抉择、幕末和终局的处理机会保持不变。

整批差量先在副本上验证、归并、更新与撤下，全部成功后才发布；失败不留下部分修改，也不确认来源已处理。失败批次保留，记录错误，下次正常机会合并重试。同次推进的重合处理机会不重复尝试失败批次。

观察、换幕和结局不以展示维护成功为前提。观察失败时恢复已提交来源，不重写正文、不重新结算或掷点。维护成功后只刷新同一事件最新抉择结果的资产快照，不改旧回合快照。

重复 ID、名称和相同字段不会解除 `retired` 或刷新变化时间；实际新变化仍沿原身份处理。

当前所在地或仍被有效结构引用的撤下对象只留最小身份；已经结束事项不再永久保护其所有旧引用。

## 观察与结局

`observe_act_closure` 使用同一次请求提交：

| decision | evidence | endingPolarity | 引擎动作 |
| --- | --- | --- | --- |
| `ongoing` | 可以为空，不参与推进 | 忽略不适用字段 | 继续当前幕 |
| `act_closed` | 本幕实际结果 | 省略 | 完成本幕并进入下一幕 |
| `run_ended` | 整局实际结果 | `good / normal / bad` | 锁定实际等级，进入现有结局渲染 |

最后一幕不能只提交 `act_closed`，须同时判断整局结果。观察输入包含完整幕间资料、实际历史、IF 整体方向与结局标准。未来安排不能作为发生证据；局部受挫不自动判负，成立的败局不以仍有翻盘可能强行续命。

观察历史使用统一摘要及本幕全部未覆盖实际经历，不再按最近三岁丢弃未压缩正文。当前事件按来源去重；只读取正式 run/effective_facts 摘要，不选任意末条摘要。

IF `endingDirections.closureBoundary` 说明局部受挫与真实提前收束的边界；既有好／普通／坏标准和各幕目标保留。

仅当前 AI 叙事流程以观察确认等级替换属性评分锁级。提前结局不补造后续幕完成，也不要求三幕全部完成。待选、持久化结果及求生先处理；按所属幕与来源去重。结局正文一次接收已确认等级、实际结果依据、IF 标准和同源历史。

## 存档、缓存与验证

新局使用版本 18。旧存档只读，不迁移或清洗正文、摘要与资产。当前叙事入口统一暂停资产召回，不另建模式开关。

固定职责、工具与稳定主持资料在前，故事历史及动态状态在后。ID、年龄、观察结果不进入 system 或 schema 枚举。失败纠正仅用于当次请求，不进入后续叙事历史。

验收分别检查事项与材料供应、失败可恢复、真实结局可达、实际叙事改善。前三项的模拟接口回归不代替最后一项的模型回放与新局正文检查；不能据此宣布全部叙事循环已经解决。

真实模型测试使用 Material/ak.txt 的限额 key，在独立临时存储中进行，不覆盖玩家对局。请求、原始返回与快照保存在被 Git 忽略的 storage/verification-*。测试入口为 scripts/live-narrative-check.mjs，不保存 key 或请求头。

本轮机制回归与真实叙事检查分别记录，参见 [本轮验证记录](NARRATIVE_V18_VERIFICATION.md)。真实新局已证实第二人称及第一幕换幕能够运行，也暴露了切断资产回流后仍存在的局部细节拖延，以及展示维护的过量登记和经过复述。实际叙事验收未通过；不能据接口回归宣布循环已解决，召回继续暂停。
