# 六类制度供应与边镇线对局校准实测

日期：2026-11-05。A—F 六类制度按用户确认的草案落实；随后按授权使用 Material 中的限额 key，在独立临时存储中试跑。没有覆盖玩家存档，没有修改掷点结果。

## 1. 本次修改及其实际作用

| 位置 | 原问题 | 已实施内容 |
|---|---|---|

| 军事世界材料 | 训练、统军和战斗较抽象，容易只写一次小队被认可 | 充实侦察、兵种、队官、步骑协同、据点控制与敌方反应；保留既有危机和人物，不增设剧情分支 |
| 既有出击组 | 将军身份、军旗与指挥范围模糊 | 节点明确镇将授偏将、一翼步骑归属及原骨干任队官；军旗身份、道具说明与友军身份同时对齐 |

| 组前门槛 | 不能沿用旧增长速度下的阈值，也不能一味降低 | 正式入伍：体魄 20、智力 14；小队训练：24、20；边境出击：28、25。逐项达标与持续准入不变 |

收益和等待调整仅适用于当前边镇线版本 20；没有为其他版本更改成长速度。没有新增年龄门槛、时间协议、属性保底、剧情审核或模型请求种类。IF 三幕目标、检定公式、持久化掷点、观察与结局职责保持不变。

## 2. 四次真实对局

四局使用不同随机种子和真实模型返回，不能当成控制变量性能比较。选择策略仅指定每次选稳健、适中或冒险，成功与失败由实际概率和单次掷点产生。

| 对局 | 配置与选择 | 实际结果 | 公开记录 / 完成组 |
|---|---|---|---|
| [基线](../storage/verification-rules-baseline-20261105/story.md) | 六类制度已贯通，尚未做本次成长与军事资料校准；适中 | 39 岁好结局，完整三幕 | 35 / 9 |
| [首次校准](../storage/verification-rules-calibrated-20261105/story.md) | 成长 +2、单年过渡，但组前门槛降得过多；适中 | 26 岁好结局；九岁入伍，年龄节奏不合格，未采用该门槛 | 32 / 9 |
| [失败分支](../storage/verification-rules-failure-20261105/story.md) | 冒险；发生两次真实失败 | 雾山夺图失败被俘，逃营失败战死；7 岁坏结局，没有重做报信事件 | 11 / 3 |
| [最终配置](../storage/verification-rules-final-20261105/story.md) | 回调为最终三组门槛；稳健 | 33 岁普通结局；有一次救援失败，继续重整与最终守关 | 40 / 11 |

失败分支发生在回调最终门槛之前；它验证的是事件失败、被俘及死亡出口，没有走到正式入伍组。最终配置的完整局已经包含成功、失败、重建、换幕与终局。

### 最终局实际经历

桦岭屯军户出生 → 与石头、霍叔共同生活和练习 → 雾山发现斥候，撤回报信成功 → 准备与新兵操练，14 岁正式入伍 → 积累士兵经历、20 岁带队 → 狼谷接回迁民 → 多队合练、夺取据点和联防截击 → 获将旗与一翼实际指挥 → 交付边道图 → 鹿鸣渡洪水救援失败，留下伤亡 → 重整后守住村民 → 敌军南下、邻城陷落 → 击退先锋 → 关城守御十七日，敌退并成立止兵界约 → 观察确认普通结局。

最终大战确实在正文发生。普通结局依据是守住一方、成立止兵界约，但外敌与朝廷隐患未消；不是因为还有隐患就继续无限等待。详细依据见 [最终观察原返回](../storage/verification-rules-final-20261105/model-0111.json)。

## 3. 普通年份是否回到约三年

按实际年龄差统计，而非请求次数。幕初等待与针对性准备分开记录：

| 区间 | 基线 | 最终配置 |
|---|---|---|
| 第一幕规划等待 | 0—4 岁，4 年 | 0—2 岁，2 年 |
| 第一幕初始准备 | 4—7 岁，3 年 | 2—3 岁，1 年 |
| 正式入伍前准备 | 10—14 岁，4 年 | 8—12 岁，4 年 |
| 第二幕规划等待 | 16—20 岁，4 年 | 14—16 岁，2 年 |
| 小队训练前准备 | 20—24 岁，4 年 | 16—18 岁，2 年 |
| 出击前准备 | 26—28 岁，2 年 | 21—24 岁，3 年 |
| 第三幕规划等待 | 31—36 岁，5 年 | 29—31 岁，2 年 |

最终三组针对性准备为 **4、2、3 年**，平均 3 年。把第二幕规划等待也计入连续普通生活，该段是 4 年；没有把它藏进准备统计。尚不能承诺不同初始属性和模型结算下每组均恰好三年，也没有通过强制发属性或硬裁年龄实现该数字。

正式入伍准备的实际依据：8 岁体魄 13、智力 12；10 岁为 19、14，尚差 1 点体魄；下一批原有两年跨度结束，12 岁为 23、16，取得准入，随后两个新兵节点在 14 岁完成入伍。这也说明“约三年”和精确三年是不同的验收结果。

首轮校准只看缩短等待，造成九岁入伍，已经据实回调；未把该局快速结束当作最终成功。

## 4. 最终请求与错误核对

- 最终局只发起三次幕初组织，每幕一次。三次均选择军职规则原文，未在幕内重做世界卡。
- 全部 17 次场景、5 次抉择背景、5 次独立结果及 12 次观察请求中，军职规则原文均出现一次；没有以另一个栏目重传。
- 按最终请求的工具集合分组，全部路由各只有一种 system 和一种工具定义。年龄、属性、掷点及当前角色变化没有改写它们。完整局的服务商前缀缓存输入为 179,584 / 376,272 token，约 47.7%；该数字不代表每个请求相同比例。
- 最终局有四次实际纠正：三次展示同步（未登记军旗、角色引用错误），一次观察（候选组为空却提交 `next_flow`）。纠正后均成功，未留下阻塞错误。不能把日志没有最终异常说成没有发生重试。
- 失败分支有一批展示同步在纠正后仍报 `event_asset_not_registered`，故事照常提交并战死收束。该展示缺更新的问题没有在本轮另改协议。
- 资产仅供展示的隔离、同年交接、事件结果与掷点没有为测试改写。

## 5. 仍未通过的叙事效果

1. **明确授职仍会被弱化。** 最终节点已经直接供应“镇将正式授你偏将”，正文却写成穆浑分出一半兵权。观察器随后先说尚未成为将军，又在无候选组的纠正请求中接受实权完成。首次校准局曾明确写出偏将，但最终配置没有稳定复现。不能把制度原文已供应等同于制度已被正确执行。证据：[授职完整请求与返回](../storage/verification-rules-final-20261105/model-0072.json)、[观察纠正](../storage/verification-rules-final-20261105/model-0092.json)。
2. **“数人、名册”仍被反复表达。** 最终局已经发生实际战斗和职责变化，但从救援到重建、最终守关仍重复报数。展示资产不回流，因此不能再把它全部归因于连续性同步。输入历史和幕初模型对身份、信任的重新强调仍可直接核查；本轮没有追加推进禁令或正文改写器。
3. **历史压缩仍然偏长。** 最终局四次压缩输出合计 8,381 token，仍保留许多局部动作和话语；基线三次为 4,057 token。不是严格同量比较，但足以说明本轮没有解决摘要冗长。最终授职请求里仍能看到逐年保留的幼年、训兵与报数细节。
4. **结局仍补出新的查核桥段。** 最终结局已评价守边结果，却另写使者查粮账和兵籍。这里不能用“三幕已完整结束”替代结局表达质量验收。

本轮未通过新增语义校验、自动补写、改观察标准或修改长期压缩协议来遮盖这些结果。六类制度中的其他五类目前仅完成静态与接口核对，实际模型对局验证仅覆盖军事线。
