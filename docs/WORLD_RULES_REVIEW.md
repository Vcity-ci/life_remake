## 本次纠正的目标

用户要求通用世界卡提供这个世界实际运行的独特秩序。军阶、军功和授职是检验例子，范围同时包括其他身份、组织、能力、资源和权利的取得、改变及失去。

上一轮删除了常识公式和作者指挥，但剩下的资料仍多是事物介绍和影响因素枚举。删减没有建立可用制度，不能以卡片变短或旧词消失证明本轮目标已经达到。

### 内容的区别

| 内容 | 例子 | 作用 |
| --- | --- | --- |
| 普通常识 | 人会生病，朋友会相助，军队需要补给 | 通常无需专门制作规则卡 |
| 世界存在 | 大衍有军镇、科举、行会、宗族与教门 | 交代舞台与行动方，仍有价值，但尚未说明如何运作 |
| 局势事实 | 阿史那烈正在聚合诸部，西北边镇欠饷 | 交代某时某地正在发生什么 |
| 世界规则 | 哪一级可以任命哪种军职，该军职实际能调哪些部伍，战功如何兑现为任命与赏赐 | 让行动与结果能够改变身份、能力和处境 |
| 作者指挥 | 每次授职后还应写一轮认可考验，完成救援也须另起手续 | 向正文安排任务，不能伪装成世界规则 |

规则不必是超自然定律，也不必由引擎计算。大衍明确选择的军制、任官、师承、财产权和组织秩序都可以是规则；“独特”指在这个世界中有确定内容，不要求凭空发明奇观。

有效制度同时说明取得后的实际作用。若只增加限制、考核和认可，却不兑现新的权限、资源或行动能力，仍会形成资格循环。规则也适用于对手和其他人物，不能全部写成主角必须完成的条件。

## 当前供应断点

1. `narrative.ts/buildTaskNarrativePlan` 以 `initialWorld` 控制静态卡选择，当前为身世或尚无幕卡的规划。正文阶段的 `activeWorldCardSources` 不通过这里取得规则原文。
2. `generateNarrativeTurnPlan` 当前不发起资产召回，返回空引用。不能假定幕内另有请求会把所需规则再找回来。
3. `NarrativeActOutline` 和 `actPreparationSchema` 只保存局势、行动方、地点、压力、利益、目的及收束含义等字段，没有规则引用或原文快照。
4. 因而现行路径是“通用卡 → 幕初模型的重新表达 → 本幕主持资料 → 正文”。制度能否完整留下取决于幕初模型是否碰巧将其挤入别的字段。
5. 人工事件组中，`campaign-formation` 已直接交付多队指挥，`general-commission` 已交付将领职权和军旗。这些是具体剧情结果；它们不能代替全世界的军制说明，新规则也不能把已经交付的结果改回待批准。

## 待确认的大衍制度草案

以下是具体的新设定提案，不是对现有文件的事实复述。没有新增人物、地名、危机或事件分支；也没有写入运行资料。军职称谓和授权范围尤其需要确认。

### A. 军职、指挥与战功

大衍军中以兵卒、队正、校尉、偏将、镇将区分常设军职。队正领一队，校尉协同数队，偏将承担一处防区的步骑指挥，镇将统辖本镇驻军。军职决定实际所属部伍和调度范围，爵位与将号不自行附带兵权。

镇将可任免本镇的队正、校尉与偏将；镇将由朝廷任免，跨镇调兵依朝廷授权。战时临时任命在军令范围内具备指挥效力，职权随撤任或该项差遣结束而转移。

练成可用部伍、守住要地、击退入侵、破围救军与夺取敌据均可构成功绩。直属主将依据已经发生的成果论功，镇将落实本镇升职与赏赐，超出其权限的封爵和国家级封赏报朝廷。战功、赏物与军职分别成立；升职同时交付对应部伍和职责。

用途：使入伍、带队、协同多队和任将各自具有不同的实际内容。具体事件仍由既有事件组承担，不追加固定胜利次数或每级一场考核。

### B. 任官、科名与差遣

书院提供学习和举荐，不直接授予官职。科举所得科名提供入仕资格，实职由朝廷按职缺授任；已有实任者在任命范围内行使职权。军功、荐举和临时差遣也是既有任用途径，不以重新参加科举才能办事。

地方官掌本辖区税役、治安、赈济与诉讼，能调度所属差役与相应官署资源；边军由军职体系指挥。朝廷的专门差遣可以临时授予明确辖区和职司，其结束交还相应职权。

用途：官职带来能够实施的行动，不停留在获得名义之后继续索取认可；同时说明文武权限在哪里相接。

### C. 行会、经营与特许

普通货物可由商户自行经营。盐铁等官营品类与军器贸易另受特许，许可限定经营者、货类和范围，由相关官署授予或收回。

行会成员可使用本会共用的仓储、运输与同业担保，也承担约定的共同费用。会外经营仍可进行，但不享有这些共有资源。商户自己的货物与铺产归其所有，共同出资的资产按合伙约定归属；退出行会不自动转让私人产业。

用途：会籍、许可和财产分别有明确作用；经营发展可以改变真实渠道和规模，而非不断抽象争取“信用”。

### D. 师承、技艺与传承

武馆可以公开授艺，入门弟子由师父收授本门技艺；被指定的传承人取得传授本门核心技艺和承接门务的权利。出师表示能够独立执业，不自行取得对同门的指挥权；代掌门务或接任掌门由门内原有主持者交付。

已经学会的武艺不因离门而消失。门规影响成员身份、共享资源和传授本门秘技的权利；不以组织认可代替个人已经具备的行动能力。

用途：学习带来会做的事，传承和主持带来可以教谁、调动什么的变化，避免把每次使用本领都变成资格证明。

### E. 共同资产、合伙与收编

个人出资与个人所得由本人处置；接受共同委托、使用共同资源取得的成果，按成立时的约定分配。合伙人的财产份额、日常经营权和共同决策权分别由约定确定，不能因一次出资或个人声望自动取得全部控制。

军队归入既有编制后，军令服从接收方的指挥体系；原首领保留或取得什么职务、原部众由谁统领，随收编安排一起确定。联盟只承担约定的援助，不自动等于合并。

用途：说明钱财、朋友、部伍与组织怎样转化成可持续的力量，也让退出、易主和联盟破裂有具体的变化对象。

### F. 教门身份、庙产与护持

教门成员的传法资格由本门师承授予，主持者掌管本处公共庙产、祭仪与救济安排。私人供养与交付教门的公共财物分别归属，受托管理不等于私人占有。

护持者提供住处、药材或庇护时，按已经成立的约定取得相应服务；护持不自动让其成为传承人或掌门。离任交还公共职权，已经学会的医术与仪轨仍归人物掌握。

本草案不规定神迹真实存在或不存在，不创造新法术。相关超自然机制需另行确定，不能让模型在每次请求中自行决定。

用途：教门可以成为真实的庇护、学习与公共行动组织，而不只是不断争论正统的背景。

## 落地所需的最小协调

制度内容确认后：

1. 将上述规则归入对应通用卡，替换只有因素枚举的部分；保留有用的地理、局势和方法知识。不把全部规则塞入全局 laws，也不对每张卡套相同固定格式。
2. IF 与事件组只引用相关通用规则，剧情结果使用相同的职权含义。已有正式入伍、多队指挥和授将结果继续有效，不补插新的手续节点。
3. 幕初在现有请求中选择适用规则引用；引擎核对已供应范围并保存对应原文快照。规则原文随本幕稳定主持资料供应，模型只组织本局局势，不重写基本制度。
4. 正文与结果使用这份稳定规则及实际历史；准备生活按相关规则取得学习、生活和任职环境。观察器仍按 IF 判断收束，不新增逐条制度验收。
5. 不恢复展示资产回流，不新增模型请求，不把规则做成属性门槛、军功点数、事件台账或引擎语义判断。两种模式共用静态规则，展示资产隔离继续保留。
6. 通过最终请求检查规则原文是否到达、是否重复、是否随动态状态改写稳定前缀；再按授权进行模型验证。不能只用文件存在或类型通过证明规则已经起效。

本轮尚未实施上述运行改动。当前结论是：缺口同时位于规则内容和规则供应，不能只改卡片措辞，也不能只增加一个未被正文消费的字段。

## 第二次复核：草案不能直接视为完整制度

六类草案已提交确认，以下复核不改变原草案，也不代表已经获得写入许可。对照现有六条 IF 后，仍有必要指出草案自身的不足，避免把另一批抽象文字写进通用卡。

| 类别 | 已经明确的部分 | 仍未做实的部分 | 落地时不能冒充已经解决的内容 |
| --- | --- | --- | --- |
| A 军职 | 有确定的职级、对应指挥范围、授职主体及战功兑现途径 | 军职称谓与授权范围属于新设定，待确认 | 不能把一次立功写成逐级考核，也不能撤销事件组已经授予的实际军权 |
| B 任官 | 区分科名、实任和差遣，地方官有实际职权 | 科名有哪些层次、官署之间的任命与执行关系尚不具体 | “朝廷按缺任命”仍不足以支撑宰辅线中实际影响任命、政策和军政资源的过程 |
| C 商业 | 区分普通经营、特许经营、会籍与私人财产 | “相关官署”“约定的费用”没有确定授权与组织决策；商网扩张可调动什么尚不明确 | 不能把“有行会、有许可”当成已经建立经营规则，更不能让普通交易也反复等待许可 |
| D 师承 | 区分学会本领、出师、传授与掌管门派 | 没有明确本世界有哪些技艺层次与能力差异，掌门交接也仍泛化 | 组织身份规则不能代替本领本身的成长；不能仅写“得到认可”便宣称可以立身江湖 |
| E 共同资产 | 区分私产、公产、军队收编和联盟 | 多处“按约定”把答案留给每次生成，没有给出本世界的默认归属与决策规则 | 不能把“约定决定分配”当成已说明所得怎样转化为可持续力量 |
| F 教门 | 区分传法、主持、公产管理与护持 | 教门授予什么具体能力仍不明确；现有古代设定未确定神异的客观效力 | 不能凭 RuneQuest 的范例擅自补入真实神术，也不能以组织名分代替医术、知识或其他实际能力 |

这不是要求六类内容采用同一张升级表。每类需要回答的问题不同：军职要有部伍和命令范围，技艺要有会做什么的区别，商业要有可调度资源与财产归属，政务要有任命和执行权，教门还涉及本世界对神异的基本选择。未经确定的部分不能靠“可以”“视情况”“按约定”填满。

RuneQuest 的教团资料把身份与具体法术、学习渠道、义务和资源恢复连接起来。它说明“加入教门后能做什么”必须有实质内容；不能据此推导大衍也存在同样的法术或宗教机制。

> 大衍常设军职为兵卒、队正、校尉、偏将、镇将。队正领一队，校尉统合数队，偏将统领一处防区的步骑，镇将统辖全镇。任职时一并交付所属部伍、辖区和职责；军令在这一范围内直接有效。将号和爵位不自行附带部伍。

>
> 带成可用部伍、守住要地、击退入侵、破围救军和夺取敌据都是论功依据。直属主将评定实际成果，镇将兑现本镇升职、部伍与赏赐；超出镇将权限的封爵和国家级封赏由朝廷决定。授职根据承担过的指挥规模与成果，可以越级任用，不以任满年限或完成固定次数战斗代替实际军功。

### 2. 科名、官职与政令

拟补入书院取士、任免与君臣权限资料；保留原有朝堂人物和派系立场。

> 大衍科名分举人、进士。州试中举者可任县级官职，京试中进士者可任中央官署或州县职务；科名是任用资格，实际职权随任命交付。书院和师门可以教学、举荐，不自行授官。军功、荐举与专门差遣也可以授任职务，不以科举作为所有人的唯一入口。
>
> 皇帝任免中央主官、州官和镇将，中央吏部办理县官任用与官员调转。县官统辖本县税役、治安、赈济和诉讼，州官统辖本州并能调度所辖县署；所属官署与差役执行职司范围内的命令。地方文官不因官阶高便接管边军，边军将领也不因兵力强便取得地方诉讼与征税权。
>
> 内阁主持议政与政务协调，各部办理本部事务；兵部承接朝廷的军队任用与调动，户部调度国家财赋，吏部负责文官任用。皇帝可以直接授予跨官署差遣，差遣中交付的权限在任命成立时生效，结束时交还。门生与同僚关系可以促成举荐、协作和政治支持，本身不转让他人的官署职权。

这里新增的科名层次、吏部和户部职权均为设定提案，不冒充原文件已有事实。它们交代入仕及影响政务的实际内容，不预写宰辅线将发生哪次考试或任命。

### 3. 商号、分号与行会

拟补入行会竞争资料；经营方法与沿途风险仍保留在各自知识卡。

> 大衍普通货物可以买卖、开铺和异地设分号，行会不垄断普通经营资格。东家处置本号资本并承担经营损益，掌柜在交付的货物、资金和业务范围内自行经营；分号取得的库存、运输线路与用人权限自交付后即可使用，不需要逐笔重新取得总号认可。
>
> 行会成员由在会商号担保、会首接纳。会内共用仓栈、运输和同业担保由成员共同出资维持，成员可使用这些实际存在的公共资源；加入行会不自动取得其他成员的私人货物与船只。会首由会内商号推举，调度公共资源并代表行会交涉，新增共同负担和处置公共产业须由在会商号过半同意。

本卡使铺号扩张、开分号、入会和掌会具有不同作用；不把财力、会籍和官府许可合成同一种“信用等级”。

### 4. 官营品类与贸易授权

拟替换官商卡中只枚举专卖、牌照和查封的部分。

> 大衍盐铁由国家专营，户部可将指定地区的运输和经销交给商号；获授权者可以在交付的货类和地域内经营，不因此垄断其他普通货物。军器生产与采购由兵部委托，军方委托只覆盖该项军需，不授予商号征税或调兵权。

这是对虚构大衍选择一套明确制度，不能作为现实历史或法律介绍。规则区分普通经营、专营和军事委托，不新增固定报验剧情。

### 5. 师承、出师与门派公产

拟补入师承和门派传承资料，不规定新的超自然境界。

> 大衍武馆的公开课程可以按学资学习；入门弟子由师父收授本门完整技艺，可以使用本门武谱、练武场和共有练功物资。出师由授业师父依据弟子独立运用本门技艺的实际本事裁定。出师者可以用本门传人的身份独立行走、受托护送或开馆教授已经获授的技艺，不需每次行动重新求取资格。
>
> 本门核心传承的授徒权由现任传承人交付。掌门可以主持门务、安排共有产业和组织共同应对，掌门继任由现任掌门指定；未指定便由已有授徒权的师长共同推举。个人武力最强不会自动取得其他同门或公产。

本卡解决学习渠道、独立行动、授徒与组织资源之间的联系。古代世界的武艺能力上限仍没有完整设定，本卡不以一套组织称谓冒充境界体系已经建成。

### 6. 合伙、个人所得与共同经营

拟补入财富去向资料；与行会资源的规定分工，不再重复写一遍会籍。

> 大衍合伙商号以各人的投入份额分配共同经营的利润与亏损，参与经营的掌柜另领取其职务报酬。掌柜负责日常经营；新增合伙人、出售全号或承担超出原有资本的债务，由持有过半份额的合伙人决定。投入财物与担任掌柜分别成立，出力任职不自动取得全号所有权。

这是一套明确的默认分配与决策规则。特殊合伙可以在成立时另有安排，但后续请求须承接本局已经成立的安排，不每轮自行重新发明。

### 7. 占领、归附与联盟

拟补入据点、收编和秩序资料，单独覆盖逐鹿线，不能被一般财产规则替代。

> 大衍县州的官署、公共仓储与地方驻军各有掌管者。攻克并控制城池的一方可以部署驻军、任用地方官并调度接管的公共仓储；此前已被带走、焚毁或仍在他人控制下的资源按其实际状态处理。命令作用于已经控制或归附的地方，邻近县州仍由其现有力量掌管。

### 8. 教门传承、主持与公共供养

拟补入教门与传承资料，保持现有世界对神异的未定边界，不新增真实神术。
