世界包 JSON 模板说明（v9）
==========================

本目录包含：
- world.example.json：前端世界名称、简介、年龄段和基础时间线配置。
- story.example.json：模型使用的世界规律、社会力量、叙事素材和数值规则。

一、使用方法
------------
1. 为新世界选择唯一 ID，例如 my_world。
2. 将 world.example.json 复制到 data/worlds/<世界ID>.json。
3. 将 story.example.json 复制到 data/narratives/<世界ID>.story.json。
4. 把两个文件内的 my_world 全部替换为同一个 ID，保持合法 JSON。
5. 新源码副本或首次初始化会从 data/worlds 载入世界列表；现有内容存储暂未提供热导入界面。

二、世界包的职责
----------------
世界包说明“这里是什么世界、哪些力量会行动、能够发生什么类型的故事”，不规定玩家必走的剧情。

- storyBible：世界总览。不要写成唯一剧情梗概。
- worldCore：每轮稳定可用的 identity、laws、powerStructure、everydayLife、tone。
- socialForces：能够产生人物、资源和压力的真实社会力量。它们不是路线，也不要求模型每轮选择。
- narrativePalette：题材常见的场景形态、冲突来源、行动词汇和故事尺度。
- storyPatterns：可选的故事形态。模型可选 0—2 项作为当轮素材，不能把它们当作互斥路线。
- styleRules：正向文风与表现材料，不写“不要做什么”的防御性清单。
- worldCards：像世界卡一样按任务、节拍、关键词、事实、人物、地点或本领动态召回的局部知识。

开局身世生成后，引擎会用玩家人设、最终天赋、身世和 worldCore 生成本局 session premise。mainlineActs 的三个条目只是既有五节拍与结局完整性的结构槽位；具体问题、压力和阶段结果由本局 premise 生成，不应在世界包里写死。

三、数值与结局
--------------
- progression.gates：世界级 opening / escalation / pressure / climax 能力门槛，不再按故事路线分别配置。
- growthFocuses、statTiers、statTierPresentation、survival：沿用现有属性成长、展示和生存规则。
- endingBlueprints：恰好提供 good、normal、bad 三项世界级结局蓝图。属性、名望、抉择轨迹和历史代价决定品质；不再为每条故事形态复制结局。
- completion：仍可要求三段完整经历、抉择后果、高潮、回收和无活动场景。

四、worldCards
--------------
- activation.tasks：background、planning、horizon、rendering、dynamic、decision。
- activation 还可使用 keys、secondaryKeys、selectiveLogic、scanDepth、actIds、beats、factionIds、factIds、characterIds、locationIds、abilityIds。
- v9 不使用 routeIds 激活世界卡。
- placement：world、scenario、example、author_note。
- priority 决定预算内优先级；inclusionGroup 同组择一；stickyTurns、cooldownTurns 和 relatedCardIds 控制生命周期。
- style_example 直接写可供模仿的短正文，不写创作说明，不放入必须复刻的专名或事实。

五、检查清单
------------
1. story JSON 的 version 为 9，两个文件 ID 与文件名一致。
2. worldCore、socialForces、narrativePalette、storyPatterns 均非空。
3. mainlineActs 保留三个结构槽位，但不预写固定案件、职业或升级路线。
4. progression 使用 gates，不使用 routes。
5. endingBlueprints 只有 good、normal、bad 三项。
6. worldCards 引用的 actIds、factionIds 与 relatedCardIds 均存在，卡片 ID 不含竖线。
7. 玩家正文不显示工具调用、内部 ID、幕名或状态标签。
